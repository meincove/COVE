# Outfit Builder Debugging Walkthrough

## 1. Issues Identified
1. **Routing Failure**: Requests with `sessionType: outfit_builder` were being intercepted by the conversation flow handler ("What's the occasion?"), preventing the multi-agent orchestrator from running.
2. **Search Failure**: Stylist agent was returning 0 candidates because the `catalog_vocab` function was querying a non-existent table (`ai_products` instead of `ai_core.docs`).
3. **UI Visibility**: 
   - `AgenticOutfitBuilder` component wasn't rendering in "Chat" mode.
   - Candidates weren't showing due to case mismatch (`tops` vs `Tops`).
   - Budget information was missing from the UI.

## 2. Fixes Implemented

### Backend Routing
Modified `app/routes/agent.py` to bypass the conversation flow check when `sessionType` is explicitly `outfit_builder`. This ensures direct routing to the Orchestrator.

```python
# app/routes/agent.py
should_skip_flow = skip_conversation_check or body.sessionType == "outfit_builder"
flow_name = None if should_skip_flow else conversation_handler.should_start_conversation(q)
```

### Product Search / Catalog
Fixed `app/vector/store.py` to use the correct table `ai_core.docs` for vocabulary extraction.

```python
# app/vector/store.py
# Fixed: ai_products -> ai_core.docs
cur.execute("""
    SELECT DISTINCT lower(c->>'colorName')
    FROM ai_core.docs, jsonb_array_elements(COALESCE(meta->'colors', '[]'::jsonb)) AS c
    ...
""")
```

### Frontend UI
1. **Enabled Visualizer**: Removed `mode === 'outfit_builder'` check in `CoveChatWidget.tsx` so the builder UI appears whenever events are present.
2. **Fixed Candidates**: Added normalization in `AgenticOutfitBuilder.tsx` to handle lowercase category names from backend.
3. **Added Budget Display**: Implemented budget tracking in `useOutfitStore.ts` and added a progress bar to the `AgenticOutfitBuilder` header.

## 3. Verification
- **Curl Test**: Verified `/ai/agent/query-stream` now streams outfit events (`agentic:category_candidates`, etc.) and returns specific items (e.g. "SimpleStack Pants").
- **UI Test**: Verified that searching for "Date night look" triggers the visual panel, shows candidates for categories (Tops/Bottoms), and displays the budget usage (e.g., €53.04 / €500.00).
