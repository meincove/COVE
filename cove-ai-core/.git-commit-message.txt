## Hardcoding Removed
**Before:**
```python
top_k = max(1, min(body.top_k or 8, 24))  # 3 hardcoded values
docs = search(top_k=top_k * 4)  # Hardcoded multiplier
```

**After:**
```python
config = get_search_config()
top_k = max(
    config['limits']['min_top_k'],
    min(body.top_k or config['defaults']['recs_top_k'],
        config['limits']['max_recs_top_k'])
)
overfetch = top_k * config['retrieval']['overfetch_multiplier']
docs = search(top_k=overfetch)
```

**Result:** ZERO hardcoded search constants!
